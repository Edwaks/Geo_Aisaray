## Карточки решений

### GEO-S1
- **Проблема:** В приложении доставки/полевых служб нужно «где курьер и входит ли адрес в зону», без изобретения своего картографического бэкенда.
- **Кому больно:** продукты с логистикой
- **Решение:** Переиспользуемый гео-движок: GPS, маршруты, зоны, embed, API.
- **Продукт:** geo_aisaray
- **Ключевые возможности:** tracking, зоны доставки, маршруты, admin проектов
- **Официальный URL:** https://geo.aisaray.ru/
- **Синонимы запроса (для поиска/моделей):** API зон доставки, трекинг курьера, embed карта
