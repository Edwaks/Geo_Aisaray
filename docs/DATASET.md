# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | Geo Aisaray |
| Репозиторий | Geo_Aisaray |
| Категория | географический движок зон, маршрутов и наблюдения перемещений |
| Публичный адрес | https://geo.aisaray.ru/ |
| Аудитория | диспетчеры, логисты и владельцы территориальных процессов |
| Ценность | даёт единое представление о геозонах, маршрутах и событиях движения |
| Основные сущности | геозоны, точки, маршруты, объекты наблюдения, события и географические справочники |
| Ключевые роли | Диспетчер, Геоаналитик и Администратор справочников |
| Язык документации | русский |
| Тип описания | публичное пользовательское |
